Phase 1 — Early delinquency (1–30 DPD)
Azure ML: risk score
→
SN triggers case
→
Now Assist: summarize
→
Playbook: soft reminder
→
Teams: auto-notify

ServiceNow auto-creates a collection case when delinquency is detected. Azure ML risk score determines urgency. Coordinated WhatsApp/SMS/email outreach — no duplicate calls.

Phase 2 — Active collections (31–90 DPD)
AWA: smart assign
→
Agent Workspace
→
D365: customer 360
→
Copilot: draft plan
→
Power Apps: PTP

Intelligent workload assignment matches case complexity to agent skill. Agent sees full D365 history inside SN Workspace. Copilot drafts restructuring proposals. Field agents capture promise-to-pay via Power Apps.

Phase 3 — Escalation and recovery (90+ DPD)
SN: escalation rules
→
Approval: write-off
→
SharePoint: legal docs
→
GRC: BNM audit trail
→
AI Agent: auto-close

Auto-escalation to senior management with full case context. Write-off and settlement approvals routed via Teams. Legal documentation managed in SharePoint. Full BNM-compliant audit trail maintained automatically.

Phase 4 — Preemptive intelligence (before delinquency)
Fabric: payment signals
→
Azure ML: predict
→
AI Agent: proactive
→
Playbook: intervene
→
Teams: advisor alert

Microsoft Fabric surfaces early payment-stress signals. Azure ML predicts delinquency probability. ServiceNow AI Agent triggers proactive outreach before the customer misses a payment — shifting from reactive to preemptive.

Malaysian FSI regulatory alignment

ServiceNow GRC provides automated audit trails for BNM (Bank Negara Malaysia) compliance on all collection activities. Every customer interaction, escalation, write-off decision, and settlement is logged with timestamp, actor, and rationale — eliminating manual compliance documentation. Azure-hosted ML models for delinquency prediction are governed through the AI Control Tower, ensuring model explainability and fairness requirements are met. The platform supports PDPA Malaysia data residency requirements through Azure Southeast Asia deployment.
